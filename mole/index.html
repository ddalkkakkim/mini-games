시간이 갈수록 두더지가 더 짧게 나오고, 동시에 나오는 수가 2 → 3 → 4마리로 늘어나요. 부장님은 한 번에 한 명만, 전체의 20% 이하로 나와요. 최고 점수(BEST)와 지금까지 잡은 두더지 수(TOTAL MOLES)는 자동 저장돼요.

⌨️ 키보드는 F8·F9·Esc 말고는 안 써요. 게임을 켜 둔 채로 엑셀에 숫자를 쳐도 그대로 입력되고, 작업 중인 창의 포커스도 빼앗지 않아요.

🙋 자주 묻는 질문

실행했는데 아무것도 안 보여요

주 모니터 왼쪽 아래, 작업표시줄 바로 위에 잔디 상자로 떠요. F8을 눌렀다면 한 번 더 누르면 다시 보여요. 골프·야구·헬리콥터 같은 다른 미니게임이 켜져 있으면 같은 자리에 겹치니 Esc로 끄고 실행해 주세요.

상자 근처를 클릭하면 뒤 창이 눌려요 / 안 눌려요

잔디 상자 안의 클릭은 게임이 받아서 뒤 창이 안 눌려요. 상자 밖의 투명한 부분은 뒤 프로그램을 그대로 클릭할 수 있어요. 상자 안에선 커서가 손 모양으로 바뀌어요.

분명 맞혔는데 점수가 안 올라요

덜 올라온 두더지는 보이는 부분만 맞아요(머리만 나왔으면 머리를 클릭). 이미 맞힌 두더지는 별이 도는 동안 다시 맞지 않아요.

점수가 마이너스가 됐어요

부장님을 때리면 −3이에요. 회색 양복에 안경 + 흰 셔츠 + 빨간 넥타이가 부장님이에요. 이번 판에 때린 수는 BOSS 칸에 나와요. BEST는 1점 이상일 때만 기록돼요.

F8로 다시 보이게 하면 어떻게 돼요?

숨긴 순간의 남은 시간·두더지 그대로 바로 이어서 진행돼요. 마우스를 상자 근처에 두고 F8을 누르세요.

끝나고 START가 회색이에요

30초가 끝나고 1초 뒤 초록색으로 바뀌면 누를 수 있어요. 막판에 연타하다 실수로 바로 새 판이 시작되지 않게 막아 뒀어요.

갑자기 꺼졌어요

Esc는 다른 창에서 눌러도 게임이 꺼져요(엑셀에서 Esc 누를 때 주의). 화면 해상도가 바뀌어도 자동 종료돼요. 다시 실행하면 기록은 그대로 남아 있어요.

기록까지 완전히 지우고 싶어요

명령 프롬프트에서 reg delete HKCU\Software\MiniMole /f 실행 후 exe를 지우면 흔적이 없어요.

회사 PC에 써도 되나요?

프로그램 자체는 인터넷을 쓰지 않지만, 실행 허용 여부는 회사마다 달라요. 사내 보안 규정을 꼭 확인해 주세요.
