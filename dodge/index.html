이 게임은 Windows PC용이에요. 링크를 PC로 보내서 받아주세요.

⬇️ 다운로드

MiniDodge.exe 받기 103KB 회사망에서 exe가 막히면 → zip으로 받기

Windows 10/11 · 64비트 · 관리자 권한 필요 없음

🎮 30초 사용법

커서 넣기
왼쪽 아래 회색 상자 안으로 커서를 넣으면 READY 1초 후 시작
피하기
상자 네 변에서 총알이 날아와요. 판정은 비행기 가운데 흰 점 하나뿐
커서 빼기
상자 밖으로 나가면 바로 일시정지 ← 누가 오면 이것!
초록 링
멈춘 자리에 뜨는 링에 커서를 다시 올려야 이어져요
F8
숨기기 / 다시 보이기 (플레이 중이면 자동 일시정지)
F9
새 판 (최고기록은 유지)
Esc
종료 (게임 위 오른쪽 클릭도 종료)

시간이 갈수록 총알이 빨라지고 많아져요. 8초마다 커서를 노리는 5발 부채꼴 탄이 와요. 총알을 아슬아슬하게 스치면 GRAZE가 올라가요. 최고기록(BEST)과 누적 GRAZE는 자동 저장돼요.

개인이 만든 무료 프로그램이라 유료 코드 서명이 없어서 뜨는 창이에요. 한 번만 하면 다음부턴 안 떠요.

🙋 자주 묻는 질문

실행했는데 아무것도 안 보여요

주 모니터 왼쪽 아래, 작업표시줄 바로 위에 작은 회색 상자로 떠요. F8을 눌렀다면 한 번 더 누르면 다시 보여요. 골프·야구 같은 다른 미니게임이 켜져 있으면 같은 자리에 겹치니 Esc로 끄고 실행해 주세요.

상자 안에서 마우스 커서가 사라져요

정상이에요. 플레이 중에는 커서 대신 초록 비행기가 보여요. 상자 밖으로 빼면 원래 커서로 돌아와요.

다시 들어갔는데 게임이 안 이어져요

일시정지하면 멈춘 자리에 초록 동그라미가 생겨요. 커서를 그 동그라미에 올려야 이어져요. (밖으로 나갔다가 안전한 곳으로 순간이동하는 건 막아 뒀어요)

맞은 뒤 다시 하려면요?

커서를 상자 밖으로 뺐다가 다시 넣으면 새 판이 시작돼요. 상자를 한 번 클릭해도 준비돼요.

갑자기 꺼졌어요

Esc는 다른 창에서 눌러도 게임이 꺼져요(엑셀에서 Esc 누를 때 주의). 화면 해상도가 바뀌어도 자동 종료돼요. 다시 실행하면 기록은 그대로 남아 있어요.

기록까지 완전히 지우고 싶어요

명령 프롬프트에서 reg delete HKCU\Software\MiniDodge /f 실행 후 exe를 지우면 흔적이 없어요.

회사 PC에 써도 되나요?

프로그램 자체는 인터넷을 쓰지 않지만, 실행 허용 여부는 회사마다 달라요. 사내 보안 규정을 꼭 확인해 주세요.
