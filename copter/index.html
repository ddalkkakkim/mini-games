천장·바닥·가운데 떠 있는 블록에 닿으면 끝. 처음 40m는 곧은 길이고, 갈수록 통로가 좁아지고 빨라져요. 판정은 헬리콥터 몸통만 봐요(꼬리·프로펠러는 닿아도 괜찮아요). 모든 동굴은 항상 빠져나갈 수 있게 만들어져요. 최고 거리(BEST)와 판 수(PLAYS)는 자동 저장돼요.

⌨️ 게임이 보이는 동안엔 X 키를 게임이 써요. 엑셀에 X를 쳐야 하면 F8로 숨기세요. 숨기면 X는 원래대로 글자가 입력돼요.

🙋 자주 묻는 질문

실행했는데 아무것도 안 보여요

주 모니터 왼쪽 아래, 작업표시줄 바로 위에 가로로 긴 동굴 상자로 떠요. F8을 눌렀다면 한 번 더 누르면 다시 보여요. 골프·야구·총알피하기 같은 다른 미니게임이 켜져 있으면 같은 자리에 겹치니 Esc로 끄고 실행해 주세요.

엑셀에서 X가 안 쳐져요

게임이 보이는 동안엔 X 키를 게임이 받아요. F8로 숨기면 바로 원래대로 입력돼요. 다시 하려면 F8 한 번 더.

너무 금방 떨어져요

아무것도 안 누르면 0.5초쯤이면 바닥에 닿아요. 꾹 누르고 있기보다 짧게 톡톡 끊어 누르기가 훨씬 쉬워요. 올라가는 힘과 떨어지는 힘이 똑같아서 누른 시간과 뗀 시간을 반반으로 맞추면 수평으로 날아요.

F8로 다시 보이게 했는데 안 움직여요

정상이에요. 다시 보이면 PAUSED로 기다려요(보이자마자 떨어져서 억울하게 끝나지 않게). X를 새로 누르면 이어져요.

부딪힌 뒤 X를 눌러도 다시 안 돼요

부딪히고 0.8초 뒤부터 다시 출발할 수 있어요. X를 누른 채로 부딪혔다면 한 번 뗐다가 다시 눌러 주세요. (실수로 바로 출발하지 않게 막아 뒀어요)

갑자기 꺼졌어요

Esc는 다른 창에서 눌러도 게임이 꺼져요(엑셀에서 Esc 누를 때 주의). 화면 해상도가 바뀌어도 자동 종료돼요. 다시 실행하면 기록은 그대로 남아 있어요.

기록까지 완전히 지우고 싶어요

명령 프롬프트에서 reg delete HKCU\Software\MiniCopter /f 실행 후 exe를 지우면 흔적이 없어요.

회사 PC에 써도 되나요?

프로그램 자체는 인터넷을 쓰지 않지만, 실행 허용 여부는 회사마다 달라요. 사내 보안 규정을 꼭 확인해 주세요.
