🙋 자주 묻는 질문

실행했는데 아무것도 안 보여요

주 모니터 왼쪽 아래에 아주 작게 떠요(그게 포인트). F8을 눌렀다면 한 번 더 누르면 다시 보여요. 전체화면 프로그램 위에서는 안 보일 수 있어요.

X를 누르면 문서에 x가 안 써져요

게임이 보이는 동안은 X가 게임 조작키예요. F8로 숨기면 다시 정상 입력돼요.

갑자기 꺼졌어요

화면 해상도가 바뀌면 자동 종료돼요. 다시 실행하면 기록은 그대로 남아 있어요.

기록까지 완전히 지우고 싶어요

명령 프롬프트에서 reg delete HKCU\Software\MiniApproach /f 실행 후 exe를 지우면 흔적이 없어요.

회사 PC에 써도 되나요?

프로그램 자체는 안전하지만, 실행 허용 여부는 회사마다 달라요. 사내 보안 규정을 꼭 확인해 주세요.
