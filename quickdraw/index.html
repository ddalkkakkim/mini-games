🤠 회사 몰래 미니게임 9탄
결투

서부 총잡이 결투. FIRE! 뜨는 순간 X 한 번. 내 반응속도를 ms(1000분의 1초)로 재요. 미리 누르면 부정출발 FOUL!

설치 없음112KB버튼 하나(X)한 판 5라운드소리 없음투명 배경

📱 지금 휴대폰이시죠?

이 게임은 Windows PC용이에요. 링크를 PC로 보내서 받아주세요.

⬇️ 다운로드

MiniQuickDraw.exe 받기 112KB 회사망에서 exe가 막히면 → zip으로 받기

Windows 10/11 · 64비트 · 관리자 권한 필요 없음

🎮 30초 사용법

X
라운드 시작 → WAIT... → 1.5~5초 뒤 빨간 FIRE!가 뜨면 바로 X
FIRE [X]
장면 아래 버튼을 마우스로 눌러도 돼요(누르는 순간 인정)
F8
숨기기 / 다시 보이기 ← 누가 오면 이것! 진행 중 라운드는 취소되고, 다시 보이면 WAIT부터
F9
새 판 (최고기록·전승 횟수는 유지)
Esc
종료 (게임 위 오른쪽 클릭도 종료)

상대보다 빠르면 WIN, 같거나 느리면 LOSE. 상대는 라운드마다 빨라져요(±20ms 랜덤).

1R420ms
2R380ms
3R340ms
4R300ms
5R260ms

FIRE! 전에 누르거나 100ms 미만(사람이 보고 반응할 수 없는 속도 = 찍기)이면 FOUL, 1초 안에 안 쏘면 TOO SLOW로 그 라운드 패배. 5라운드가 끝나면 승수·평균(AVG)·최고(BEST)가 나오고, 5전 전승이면 PERFECT! 역대 최고 반응(BEST)과 전승 횟수(5/5 WINS)는 자동 저장돼요.

⌨️ 게임이 보이는 동안엔 X 키를 게임이 써요. 엑셀에 X를 쳐야 하면 F8로 숨기세요. 숨기면 X는 원래대로 글자가 입력돼요.

🙋 자주 묻는 질문

실행했는데 아무것도 안 보여요

주 모니터 왼쪽 아래, 작업표시줄 바로 위에 총잡이 둘이 마주 선 작은 장면으로 떠요. F8을 눌렀다면 한 번 더 누르면 다시 보여요. 골프·야구·헬리콥터 같은 다른 미니게임이 켜져 있으면 같은 자리에 겹치니 Esc로 끄고 실행해 주세요.

엑셀에서 X가 안 쳐져요

게임이 보이는 동안엔 X 키를 게임이 받아요. F8로 숨기면 바로 원래대로 입력돼요. 다시 하려면 F8 한 번 더.

빨리 눌렀는데 FOUL이 떠요

FIRE!가 뜨기 전에 누르면 부정출발이에요. FIRE! 뒤라도 100ms 미만이면 보고 누른 게 아니라 찍은 걸로 보고 FOUL이에요. 대기 시간이 1.5~5초로 매번 달라서 리듬으로 맞출 수 없어요.

기록이 생각보다 느리게 나와요

반응시간은 FIRE!를 화면에 그린 순간부터 X 키 신호가 들어온 순간까지예요. 모니터가 실제로 빛을 내기까지의 지연과 키보드 자체 지연은 잴 수 없어서, 순수한 사람 반응보다 몇~수십 ms 크게 나와요. 다른 PC·모니터와 비교할 땐 참고해 주세요.

화면에 (X polled: +-16 ms)가 떠요

X 키를 쓰는 다른 미니게임(헬리콥터 등)이 켜져 있어서 X 단축키를 등록하지 못한 상태예요. 이때는 보조 방식으로 동작해 측정 오차가 최대 약 16ms 생기고, 뒤 프로그램에도 X가 입력될 수 있어요. 다른 게임을 Esc로 끄고 다시 실행하세요.

F8로 숨겼다 다시 보이면 어떻게 돼요?

WAIT 중이거나 FIRE!가 떠 있을 때 숨기면 그 라운드는 취소돼요(숨긴 동안 FIRE!가 나오지 않게). 다시 보이면 새 랜덤 대기 시간으로 WAIT부터 다시 시작하니 바로 준비하세요.

판이 끝났는데 X를 눌러도 새 판이 안 돼요

결과가 뜬 뒤 0.5초 동안은 X를 받지 않아요. X를 누르고 있었다면 한 번 뗐다가 다시 눌러 주세요. 누르면 바로 새 판 1라운드 WAIT가 시작돼요.

갑자기 꺼졌어요

Esc는 다른 창에서 눌러도 게임이 꺼져요(엑셀에서 Esc 누를 때 주의). 화면 해상도가 바뀌어도 자동 종료돼요. 다시 실행하면 기록은 그대로 남아 있어요.

기록까지 완전히 지우고 싶어요

명령 프롬프트에서 reg delete HKCU\Software\MiniQuickDraw /f 실행 후 exe를 지우면 흔적이 없어요.

회사 PC에 써도 되나요?

프로그램 자체는 인터넷을 쓰지 않지만, 실행 허용 여부는 회사마다 달라요. 사내 보안 규정을 꼭 확인해 주세요.
