🎮 30초 사용법

X
누르는 순간 발사. 상자 위 SHOOT [X] 버튼을 클릭해도 돼요
WIND
화살은 화살표 방향으로 밀려요. 1 m/s마다 7픽셀 — 링 한 칸(6픽셀)보다 조금 더
F8
숨기기 / 다시 보이기 ← 누가 오면 이것! 숨긴 동안 흔들림·화살이 멈춰요
F9
새 세트 (최고기록·누적 X-10은 유지)
Esc
종료 (게임 위 오른쪽 클릭도 종료)

한 세트는 6발, 최대 60점. 가운데 노랑 10점부터 바깥 흰색 1점까지, 과녁 밖은 M(0점). 선에 걸치면 높은 점수로 쳐요(실제 양궁 규칙). 10점 안의 작은 원은 X-10 — 점수는 10점과 같고 개수를 따로 세요. 바람은 화살마다 0.0~6.0 m/s, 8방향으로 바뀌고 정답 위치는 표시하지 않아요. 최고 세트 점수(BEST)와 누적 X-10은 자동 저장돼요.

⌨️ 게임이 보이는 동안엔 X 키를 게임이 써요. 엑셀에 X를 쳐야 하면 F8로 숨기세요. 숨기면 X는 원래대로 글자가 입력돼요.

🙋 자주 묻는 질문

실행했는데 아무것도 안 보여요

주 모니터 왼쪽 아래, 작업표시줄 바로 위에 작은 궁수와 과녁이 떠요. F8을 눌렀다면 한 번 더 누르면 다시 보여요. 골프·야구·두더지잡기 같은 다른 미니게임이 켜져 있으면 같은 자리에 겹치니 Esc로 끄고 실행해 주세요.

엑셀에서 X가 안 쳐져요

게임이 보이는 동안엔 X 키를 게임이 받아요. F8로 숨기면 바로 원래대로 입력돼요. 다시 하려면 F8 한 번 더.

가운데를 조준했는데 10점이 안 나와요

바람 때문이에요. 화살은 WIND 화살표 방향으로 1 m/s마다 7픽셀 밀려요. 예) 오른쪽(→) 2.0 m/s면 조준점이 가운데에서 왼쪽으로 14픽셀(링 두 칸 남짓) 갔을 때 쏘면 10점. 바람이 0.0이면 다이얼에 점만 찍히고 밀리지 않아요.

기다릴수록 흔들림이 커져요

정상이에요. 활을 오래 당기고 있으면 1초에 6%씩, 최대 1.4배까지 흔들림이 커져요. 흔들리는 모양은 화살마다 달라요.

6발 다 쏜 뒤 X를 눌러도 안 넘어가요

마지막 점수가 1초 동안 표시된 뒤 「SET 점수」가 나오면 X(또는 NEW SET [X] 버튼)로 새 세트예요. X를 누른 채로는 안 넘어가요. 한 번 뗐다가 다시 눌러 주세요.

F8로 다시 보이게 하면 어떻게 돼요?

숨긴 순간 그대로 이어져요. 숨긴 동안엔 흔들림·날아가던 화살·점수 표시 시간이 모두 멈춰 있어요.

게임 근처를 클릭하면 뒤 창이 안 눌려요

그림이 없는 투명한 부분은 뒤 프로그램을 그대로 클릭할 수 있어요. 글자·과녁·버튼 위의 클릭은 게임이 받아요(버튼 말고는 아무 동작 없음).

갑자기 꺼졌어요

Esc는 다른 창에서 눌러도 게임이 꺼져요(엑셀에서 Esc 누를 때 주의). 화면 해상도가 바뀌어도 자동 종료돼요. 다시 실행하면 기록은 그대로 남아 있어요.

기록까지 완전히 지우고 싶어요

명령 프롬프트에서 reg delete HKCU\Software\MiniArchery /f 실행 후 exe를 지우면 흔적이 없어요.

회사 PC에 써도 되나요?

프로그램 자체는 인터넷을 쓰지 않지만, 실행 허용 여부는 회사마다 달라요. 사내 보안 규정을 꼭 확인해 주세요.
