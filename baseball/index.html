🙋 자주 묻는 질문

실행했는데 아무것도 안 보여요

주 모니터 왼쪽 아래, 작업표시줄 바로 위에 아주 작게 떠요(그게 포인트). F8을 눌렀다면 한 번 더 누르면 다시 보여요. 골프 등 다른 미니게임이 켜져 있으면 Esc로 끄고 다시 실행해 주세요.

X를 누르면 문서에 x가 안 써져요

게임이 보이는 동안은 X가 스윙 키예요. F8로 숨기면 다시 정상 입력돼요.

갑자기 꺼졌어요

Esc는 다른 창에서 눌러도 게임이 꺼져요(엑셀에서 Esc 누를 때 주의). 화면 해상도가 바뀌어도 자동 종료돼요. 다시 실행하면 기록은 그대로 남아 있어요.

기록까지 완전히 지우고 싶어요

명령 프롬프트에서 reg delete HKCU\Software\MiniDiamond /f 실행 후 exe를 지우면 흔적이 없어요.

회사 PC에 써도 되나요?

프로그램 자체는 안전하지만, 실행 허용 여부는 회사마다 달라요. 사내 보안 규정을 꼭 확인해 주세요.
