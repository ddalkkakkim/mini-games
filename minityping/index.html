'보고서', '전체회신', 'ASAP', '확인 부탁드립니다' 같은 회사 단어·문장이 떨어져요. 놓친 업무는 서류 더미로 쌓이고, 다 차면 야근 확정(게임 오버). 연속으로 처리하면 콤보, 점수가 오르면 레벨업과 함께 빨라져요. 최고 점수는 자동 저장돼요.

⚠️ 솔직하게 말씀드려요: 70곳 중 6곳이 '악성'으로 표시했어요.
V3·알약·Avast·AVG 등 나머지 64곳은 정상이에요. 6곳 모두 오탐 신고를 해 두었고, 판정이 덜 나오도록 프로그램을 수정하고 있어요. 찜찜하시면 판정이 풀린 뒤에 받으셔도 괜찮아요.

오탐이라고 보는 이유

  • 악성코드 이름이 하나도 없어요. 6곳의 판정은 CrowdStrike malicious_confidence_60%, Trapmine malicious.moderate.ml.score, Arctic Wolf Unsafe, SecureAge Malicious, Bkav·McAfee는 파일 지문을 그대로 이름으로 쓴 판정이에요. 특정 바이러스를 찾은 게 아니라 AI·평판 점수로 "의심스럽다"고 추정한 결과예요.
  • 처음 보는 무서명 파일이라 점수가 낮아요. 개인이 만든 37KB짜리 새 파일이라 코드 서명도, 다운로드 이력도 없어요. 이런 파일은 기능과 상관없이 평판 점수가 낮게 나와요.
  • 게임 방식이 의심 패턴과 겹쳐요. 숨기기용 전역 단축키(F7·F8), 항상 위에 뜨는 투명 창, 입력창으로 포커스 가져오기는 게임엔 꼭 필요하지만, AI 판정은 이 조합을 수상하게 보기도 해요.
  • 위험한 동작이 없어요. 인터넷 통신 코드, 파일 생성·삭제 코드, 자동 실행 등록, 키보드 후킹이 없어요. 레지스트리에는 최고 점수 하나만 저장해요(HKCU\Software\MiniKeys).
파일 지문(SHA256) — 받은 파일이 이 값과 같으면 원본이에요.

🙋 자주 묻는 질문

실행했는데 아무것도 안 보여요

실행하면 화면에 작게 "F7 키로 업무 시작!"이 떠요. F7을 누르면 시작돼요. F8을 눌렀다면 한 번 더 누르면 다시 보여요. 다른 미니게임이 켜져 있으면 Esc로 끄고 다시 실행해 주세요.

타자 치는데 문서에 글자가 안 써져요

게임이 진행 중일 땐 입력이 게임 입력창으로 가요. F7로 일시정지하거나 F8로 숨기면 원래 하던 창에 정상 입력돼요.

한글이 안 쳐져요

입력창이 선택된 상태에서 한/영 키로 바꿔 주세요. 한글 단어와 영어 단어가 섞여서 나와요.

기록까지 완전히 지우고 싶어요

명령 프롬프트에서 reg delete HKCU\Software\MiniKeys /f 실행 후 exe를 지우면 흔적이 없어요.

회사 PC에 써도 되나요?

프로그램 자체는 안전하지만, 실행 허용 여부는 회사마다 달라요. 사내 보안 규정을 꼭 확인해 주세요.
