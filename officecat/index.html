OfficeCat.exe 받기 73MB 회사망에서 exe가 막히면 → zip으로 받기

상태창에서 이 네 가지를 챙겨 주세요.

  • 🍚 배고픔 → 밥주기
  • 💧 갈증 → 물주기
  • 🧻 화장실 → 화장실청소
  • 💗 친밀도 → 놀아주기·쓰다듬기

놀아주기를 누르면 장난감이 랜덤으로 나와요(낚싯대·레이저·공 등 9종). 공은 끌어서 던질 수 있어요. 졸려 보이면 수면 버튼으로 재워 주세요.

⚙️ 설정 (상태창 톱니바퀴)

  • 털색 흰색 · 치즈 · 회색 · 턱시도 · 삼색이
  • 고양이 크기 작게 · 보통 · 크게
  • 활동량 차분 · 보통 · 활발
  • 투명도 · 사운드와 볼륨 · 항상 위에 표시
  • 고양이 부르기 · 화장실 제자리 · 프로그램 종료

설정창 맨 아래 프로그램 종료를 두 번 누르면 꺼져요. 상태는 자동 저장되고, 다시 켜면 그대로 이어져요.

🛡️ 처음 실행할 때 파란 창이 뜨면

  1. 추가 정보를 누르고
    Windows의 PC 보호
    Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다.
    추가 정보
    실행 안 함
  2. 실행을 누르면 끝
    Windows의 PC 보호
    앱: OfficeCat.exe
    게시자: 알 수 없는 게시자
    실행실행 안 함

개인이 만든 무료 프로그램이라 유료 코드 서명이 없어서 뜨는 창이에요. 한 번만 하면 다음부턴 안 떠요.

🔒 안심하고 쓰세요

  • 인터넷 접속 없음
  • 자동 실행 등록 없음 · 키보드 후킹 없음
  • 설치 안 함 → exe 지우면 삭제 끝 (저장 파일은 %APPDATA%\OfficeCat)
파일 지문(SHA256) — 받은 exe가 이 값과 같으면 원본이에요.

🙋 자주 묻는 질문

실행했는데 고양이가 안 보여요

처음 켤 때는 고양이가 뜨기까지 몇 초 걸려요. 그래도 안 보이면 작업표시줄 오른쪽 아래 고양이 아이콘(트레이)을 눌러 「고양이 부르기」를 해 주세요. exe를 한 번 더 실행해도 켜져 있는 고양이를 불러와요.

고양이가 창을 가려서 일에 방해돼요

고양이를 끌어서 구석으로 옮기거나, 설정에서 크기 작게 · 투명도 낮추기 · 활동량 차분으로 바꿔 보세요. 「항상 위에 표시」를 끄면 다른 창 뒤로 숨어요.

프로그램을 끄면 고양이가 굶나요?

꺼져 있던 시간만큼 조금 배고파지지만, 아무리 오래 비워 둬도 크게 굶은 상태로 돌아오진 않아요. 다시 켜서 밥 한 번 주면 돼요.

소리가 나요 / 끄고 싶어요

설정의 사운드를 끄거나 볼륨을 줄이면 돼요.

완전히 지우고 싶어요

프로그램을 종료하고 exe를 지운 뒤, %APPDATA%\OfficeCat 폴더까지 지우면 흔적이 없어요. (탐색기 주소창에 그대로 붙여넣으면 열려요)

회사 PC에 써도 되나요?

프로그램 자체는 인터넷을 쓰지 않지만, 실행 허용 여부는 회사마다 달라요. 사내 보안 규정을 꼭 확인해 주세요.
